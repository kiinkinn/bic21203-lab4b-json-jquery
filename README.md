## Lab Description
This lab focuses on creating and retrieving JSON data using the Fetch API and performing DOM manipulation using jQuery.

## Questions

### Question 1 – Create JSON File
Created a `books.json` file containing information about two books, including their titles, authors, publication years and genres.

### Question 2 – Retrieve JSON Data Using Fetch API
Used the Fetch API to retrieve information from `books.json` and display the book details dynamically on the webpage.

### Question 3 – jQuery DOM Operations
Used jQuery methods such as `.text()`, `.addClass()` and `.on()` to modify webpage elements, apply CSS styling and handle button click events.

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `books.html` and select **Open with Live Server** to run Question 2.
5. Right-click `jquery-dom.html` and select **Open with Live Server** to run Question 3.
